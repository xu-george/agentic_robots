Agentic Robots: Current Main Structure

A planner-safe robot stack: services -> APIs -> environments -> agent runtime -> results -> learning feedback.

1. Agent / Planner

CodeAgent

LLM loop that writes short Python task programs.

  • Task description
  • API docs
  • Scene context
  • Diagnostics + retry

AgentRuntime

Executes generated code only against allowlisted functions.

no imports small builtins safe API calls

Planner Output

generated_code.py, stdout, runtime status, task success, attempt history.

2. High-Level APIs

ActionApi

Robot-only control interface.

  • get_end_effector_pose()
  • move_to_pose(pos, quat)
  • open_gripper()
  • close_gripper()

PerceptionApi

Planner-safe perception + grasp API.

  • get_observation()
  • segment_object(rgb, prompt)
  • get_object_pose(...)
  • get_finger_grasp(...)

Data Types

ObjectPose GraspPose Sam3Mask GraspPlan

3. Services

Qwen Service

Local LLM chat/completion service.

/chat ChatResult

SAM3 Service

Text and point-prompt segmentation.

/segment mask + box + score

GraspNet Service

Contact-GraspNet grasp generation.

/plan 4x4 grasps scores

PyRoKi Motion

Experimental motion waypoints and joint planning.

waypoints joint states

Observation

5. Results / Learning

Task Outputs

JSON results, generated code, stdout, overlays, videos, grasp arrays.

Evaluation

runtime_success, task_success, failure reason, attempt count, diagnostics.

Skill Memory

Future storage for reusable skills, examples, traces, and fine-tuning data.

Data Flow And Interfaces

ObservationRealSense / PyBullet -> rgb, depth, intrinsics, camera_pose, robot state.
SegmentationSAM3: image + text prompt -> masks, boxes, scores.
Grasp PlanningGraspNet: depth + intrinsics + segmap -> 4x4 grasps, scores, contacts.
API ObjectsObjectPose, GraspPose, GraspPlan become planner-safe data.
Agent CodeCodeAgent writes high-level Python using only exposed APIs.
ExecutionActionApi -> FrankaSim or FrankaReal: move, open, close.
Feedbacksuccess/failure, overlays, videos, traces feed future skill learning.
